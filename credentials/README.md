# Credentials Folder

Folder ini untuk menyimpan file credentials Google Cloud Vision.

## Upload via Settings

1. Buka **Settings** → **AI & Integrations**
2. Scroll ke "Google Cloud Vision (Receipt OCR)"
3. Klik **"Upload JSON File"**
4. Pilih file credentials yang sudah didownload dari Google Cloud
5. File akan otomatis tersimpan di folder ini

## File yang Disimpan

- `google-vision-credentials.json` - Credentials untuk Google Cloud Vision API

## Security

⚠️ **PENTING**: File credentials tidak akan di-commit ke Git (sudah ada di .gitignore)

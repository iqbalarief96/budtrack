# ⚡ QUICK START - FITUR BARU

## 📊 Budget Forecast
**Lokasi:** Dashboard → Edit Mode → Tambah Widget → "Budget Forecast"

**Fungsi:** Prediksi apakah budget akan exceed

**Status:**
- 🟢 On Track - Aman
- 🟡 Warning - Hati-hati
- 🔴 Danger - Bahaya!

---

## 📥 Bank Import
**Lokasi:** Transactions → "Import Bank Statement"

**Steps:**
1. Download CSV dari internet banking
2. Pilih wallet tujuan
3. Pilih bank format (atau Auto-detect)
4. Upload file
5. Done!

**Supported Banks:** BCA, Mandiri, BRI, BNI, Generic

---

## 🔄 Recurring Automation
**Lokasi:** Recurring → "Add Recurring Transaction"

**Setup:**
1. Buat recurring transaction (Netflix, Gaji, dll)
2. Sistem auto-create setiap hari jam 00:00
3. Lihat upcoming di Dashboard widget

**Manual Actions:**
- ▶️ Create Now - Buat sekarang
- ⏭️ Skip Next - Skip occurrence berikutnya

---

## 🎨 Cara Tambah Widget
1. Dashboard → Klik ✏️ (Edit Mode)
2. Klik "Tambah Widget"
3. Pilih widget
4. Klik "Simpan Perubahan"

---

## 🆘 Quick Troubleshooting
- **Widget tidak muncul?** → Refresh page
- **Import gagal?** → Check CSV format
- **Recurring tidak jalan?** → Check cron job
